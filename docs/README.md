# KTransformers + LLaMA-Factory Documentation

This directory contains documentation for running KTransformers with LLaMA-Factory in Docker.

## Directory Structure

- **`setup/`** - Setup and installation guides
- **`docker/`** - Docker-specific documentation
- **`usage/`** - Usage guides and examples
- **`troubleshooting/`** - Troubleshooting guides and fixes

## Quick Start

1. **Docker Setup**: See [`docker/LLAMA_FACTORY_DOCKER_SETUP.md`](docker/LLAMA_FACTORY_DOCKER_SETUP.md)
2. **Running Models**: See [`usage/MODEL_RUNNING_GUIDE.md`](usage/MODEL_RUNNING_GUIDE.md)
3. **Troubleshooting**: See [`troubleshooting/FLASHINFER_FIX_COMPLETE.md`](troubleshooting/FLASHINFER_FIX_COMPLETE.md)
